# PART IV

# APPEARANCE CUTSCENE 2.0

# 19. REPLACE / REFINE HF2 CUTSCENE

HF2 introduced the first Appearance transition.

Beta 0.991 should replace/refine it with the new definitive sequence.

---

# 20. EXACT THEME SWITCH CUTSCENE

The sequence must be:

```text
CURRENT THEME ACTIVE

↓

LIGHT FLICKERS

↓

SCREEN POWERS OFF

↓

FULL BLACK BACKGROUND

↓

A REAL POWER CABLE / WIRE APPEARS

↓

PLUG APPEARS USING CURRENT THEME COLOR

↓

CURRENT PLUG IS DISCONNECTED

↓

PLUG CHANGES TO NEW THEME COLOR

↓

POWER CABLE / WIRE ALSO CHANGES TO NEW THEME COLOR

↓

NEW PLUG IS CONNECTED

↓

NEW THEME TECHNOLOGICAL DETAILS RISE ON THE BLACK SCREEN

↓

FINAL LIGHT FLICKER

↓

SCREEN POWERS BACK ON

↓

NEW THEME IS REVEALED

```

---

# 21. INITIAL FLICKER

The interface should briefly flicker like an electrical power interruption.

Do not make the effect excessively bright.

---

# 22. BLACKOUT

After the flicker:

```text
SCREEN = BLACK

```

No visible old-theme UI should remain behind the main cutscene.

---

# 23. POWER CABLE

Display an actual recognizable electrical cable.

Not merely:

```text
abstract lines

```

It should clearly read as:

```text
POWER CABLE
+
PLUG

```

---

# 24. CURRENT THEME PLUG

The initial plug should contain the current Appearance identity.

Example:

```text
current accent color
current theme lighting
current theme small details

```

---

# 25. DISCONNECT

Animate the current plug being physically unplugged.

The action should clearly communicate:

```text
OLD THEME DISCONNECTED

```

---

# 26. COLOR CHANGE

While disconnected:

```text
plug color
+
cable color

```

transition to the new Appearance identity.

---

# 27. RECONNECT

The new-theme plug reconnects.

On connection:

- small electrical pulse
- controlled glow
- small energy reaction

Avoid large flashes.

---

# 28. TECHNOLOGICAL DETAILS

After reconnection, while the screen is still black:

New-theme technological visual elements rise into view.

Possible details:

- circuit traces
- HUD lines
- energy paths
- geometric signals
- digital markings
- theme-specific patterns

These details must use the NEW theme identity.

---

# 29. FINAL FLICKER

After the technological activation:

```text
LIGHT FLICKERS AGAIN

```

Then the GameIndex interface returns fully styled with the new Appearance.

---

# 30. CUTSCENE DURATION

Target:

```text
~2.0–3.0 seconds

```

It should feel cinematic but still fast.

---

# 31. PERFORMANCE

Prefer:

```text
CSS
DOM
SVG
small lightweight assets

```

Do NOT require:

```text
large video
WebGL
heavy particle engine
large animation framework

```

---

# 32. SAFETY TIMEOUT

The cutscene must NEVER trap the interface.

Use a maximum timeout.

Example:

```text
MAX_THEME_TRANSITION ≈ 3500ms

```

If something fails:

```text
apply new theme
remove cutscene
restore interaction

```

---

# 33. RAPID INPUT

Do not allow multiple theme cutscenes to stack.

Use:

```text
LATEST VALID THEME WINS

```

or lock theme selection until transition completes.

---

# 34. REDUCED MOTION

Respect:

```text
prefers-reduced-motion

```

Reduced mode should use:

```text
short flicker
fade to black
theme switch
fade back

```

without the full cable animation.

---

IMPORTANT:

Beta 0.991 should NOT introduce a full global cutscene engine.

Do NOT add:

- Lobby Entry Cutscene
- Game Opening Cutscene

- Build Complete Cutscene

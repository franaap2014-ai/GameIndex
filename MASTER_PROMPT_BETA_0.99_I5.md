# GameIndex Beta 0.99 I5 — Implementation Contract

Internal release: `0.99-I5`  
Public version: `Beta 0.99`

I5 consolidates five pillars:
1. Content + Visual Intelligence 2.0.
2. Universe Builder UX 3.0.
3. Admin Control Center 2.0.
4. Social 2.0.
5. Production Consolidation: Bug Tracker 2.0, Regression Center and version consistency.

Non-negotiable rules:
- preserve the I4 three-stage Universe pipeline;
- reject legal/copyright/navigation/cookie boilerplate from game content;
- APPROVED assets still require semantic/role/entity compatibility;
- RICH cannot be ready with unresolved Hero, missing required visuals, excessive reuse, weak semantic matches, poor Visual Gap or stale Preview;
- use real game-sourced visual identity only, never script-generated substitute game art;
- Simple Mode by default, Advanced Mode for technical internals;
- user/role management must be easy to find but remain server-authorized and audited;
- Social must integrate Games/Experiences without deleting existing Social data;
- old bugs must be reverified, never silently marked fixed;
- public-facing UI must show `Beta 0.99`, while I/HF identifiers remain technical;
- preserve `LOCAL_FIRST_NO_API_KEY`, Node/Express/SQLite/Azure compatibility and existing user/content/database data.

Final goal: make GameIndex understandable, manageable, visually rich and production-consistent.
